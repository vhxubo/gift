# 礼簿

一个移动端优先的 React 礼金记录工具。支持多个项目，数据保存在当前浏览器本地，无需账号或后端服务。

## 功能

- 多项目独立管理礼金记录
- 记录昵称（必填）、真实姓名（可选）、金额、收款方式、男方/女方及备注
- 按昵称或真实姓名搜索
- 编辑、删除记录，并提示重复昵称
- 按归属、收款方式、礼金排行和项目总额统计
- 导出全部数据为 JSON，并通过备份文件全量恢复
- 手机端优先布局，支持系统深色模式和减少动态效果设置

## 本地运行

需要 Node.js 和 [pnpm](https://pnpm.io/)。

```bash
pnpm install
pnpm dev
```

访问终端显示的本地地址，默认通常为 `http://localhost:5173`。

网络不可用时，可通过本地代理安装依赖：

```bash
HTTP_PROXY=http://127.0.0.1:10809 \
HTTPS_PROXY=http://127.0.0.1:10809 \
pnpm install
```

## 构建

```bash
pnpm build
pnpm preview
```

生产文件生成在 `dist/` 目录。

## 数据说明

数据存储在浏览器 `localStorage` 的 `gift-ledger-v1` 键中，只在当前浏览器和当前站点地址下可用。

- 清理浏览器数据、切换浏览器或更换设备前，请先导出 JSON 备份。
- “全量导入备份”会覆盖本机已有的全部项目和记录，操作前会二次确认。
- 备份文件包含完整礼金数据，请妥善保管。
